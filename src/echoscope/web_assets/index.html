GUÍA PASO A PASO

Cómo recibir reseñas

  1. Abrí en el navegador la página donde se leen las reseñas. Copiá la dirección de esa página.
  2. Elegí Agregar una página de reseñas. Poné un nombre que reconozcas y pegá la dirección que copiaste.
  3. Elegí Buscar reseñas en la página. EchoScope buscará una lista pública de reseñas que pueda leer automáticamente.
  4. Si la encuentra, elegí Guardar fuente. Con el seguimiento activo, entrá a Fuentes → Consultar ahora o esperá la próxima consulta. Podés ver el resultado en la columna de estado.

Si no se encuentra una lista: algunas páginas muestran reseñas en el navegador pero no ofrecen una lista pública para importar. Pedile al sitio el enlace de su lista de reseñas (también llamada RSS o Atom) o probá con otra página. Si ya tenés ese enlace, pegalo directamente y guardá la fuente.
